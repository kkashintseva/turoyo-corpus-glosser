# Глагольный парсер Ṭuroyo: первая версия

Парсер работает только как слой **подсказок** для слов, у которых ещё нет
морфологического анализа. Он не заменяет точный анализ из FLEx и не меняет
слова, которые уже правил пользователь.

## Жёсткое правило сохранности

Запрос к парсеру отклоняется сервером, если у токена есть хотя бы одно из
следующего:

- `original_analysis` — исходный анализ FLEx;
- `imported_igt` — импортированный IGT;
- `locked = true`;
- морфема с `origin = user`;
- уже заполненная глосса/подсказка;
- уже задано более одной морфемы или явная граница `-`, `=` или `+`.

Таким образом, даже прямой POST к API не может применить правило поверх
импортированного FLEx-разбора.

## Откуда берётся глагольная основа

Правило окончания само по себе недостаточно. Парсер строит read-only индекс
глагольных основ из уже импортированного корпуса FLEx. Строка корпуса считается
глагольным свидетельством, если это подтверждается POS/FieldWorks-категорией
или глоссой типа `.infc`, `.pret`, `.intr.pret`, `.ipv` и т. п.

После снятия предполагаемого окончания остаток должен:

1. либо точно совпасть с засвидетельствованной глагольной основой;
2. либо иметь тот же строгий согласный каркас. Вокализм может различаться,
   согласные — нет (`š != s`, `ḥ != h`, `b != v`; `w/y` считаются согласными).

Без такого свидетельства кандидат не показывается.

## Реализованные правила

Первая версия включает:

- Infectum / intransitive preterite: `-o-no`, `-i-na`, `-i-tu`, `-utu`,
  `-at`, `-no`, `-o`, `-i`, а также засвидетельствованные `-ən/-әn` plural;
- past: `-wa`, `-o-wa`, `-at-wa`, `-i-wa`, `-ut-wa`, `-way-no`,
  `-o-way-no`, `-i-way-na`;
- L-preterite: `-le`, `-la`, `-lux`, `-lax`, `-li`, `-lan`, `-xu` и более
  осторожные 3p-allomorphs `-ḥe/-me/-lle`;
- стабильные формы L-preterite + past до A.1p; противоречивые 3p/2p формы из
  исходной инструкции (`-wal-xu`, `-wa-lle`) пока намеренно не обобщены;
- явно приведённые object patterns для infectum и L-preterite;
- imperative plural `-u`;
- verbal preverbs `k=/kə=/kә=/ko=`, `g=/gəd=/gәd=`, `ṭro=`, `kalko=`.

Префикс отделяется только в том случае, если оставшаяся часть уже получила
валидный глагольный разбор.

## Интерфейс

Для подходящего слова меню **Слово → Глагольный разбор…** показывает до 12
вариантов. Для каждого видны сегментация, глосса, правило и корпусное
свидетельство. Кнопка **Применить этот разбор** появляется как действие
редактора и требует «пера».

Принятый вариант записывается только в этот токен как `origin=user` и
`locked=true`. Он **не** становится reusable автоматически и не меняет другой
текст. Если вариант надо потом распространить, для этого остаётся существующая
команда «Запомнить для всех текстов».
