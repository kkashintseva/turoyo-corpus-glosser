# Turoyo Corpus Glosser — краткая инструкция

## 1. Запуск

```bash
source .venv/bin/activate
turoyo-glosser edit
```

Откройте `http://127.0.0.1:8000`.

## 2. Импорт источников

На стартовой странице можно загрузить:

- FieldWorks `.lift` и при необходимости `.lift-ranges`;
- корпус `.flextext` / XML;
- DOCX с уже готовой IGT-разметкой.

LIFT задаёт lexical-entry identity, senses, variants и `grammatical-info`.
FLEXTEXT даёт корпусные употребления, разборы, частоты и контексты.

## 3. Новый текст

Создайте текст на стартовой странице. Одна строка ввода становится одним
интерлинейным блоком. Для известных слов программа предлагает разборы из
импортированного корпуса; неизвестные формы остаются неразобранными.

## 4. Редактирование

Можно отдельно менять:

- исходную строку;
- сегментацию;
- морфемные глоссы;
- lexical entry / lemma;
- sense;
- перевод;
- комментарии и обсуждения;
- аудио и таймкоды.

Границы `-`, `=` и `+` различаются и сохраняются как введены.

## 5. Reusable-правки

Подтверждённый разбор словоформы можно сохранить как reusable. Он получает
приоритет над статистикой FLEXTEXT при следующем появлении той же формы.
Новое lexical значение также сохраняется и затем предлагается повторно.

## 6. FieldWorks LIFT

Разные LIFT entries не объединяются автоматически. Если одна surface form
принадлежит нескольким entries, редактор показывает их отдельно. Точное
`grammatical-info` выбранной entry/sense сохраняется в данных и выводится в
лексиконе и CSV/JSON.

## 7. Словник

В разделе **Словник** можно:

- открыть entry и её senses;
- посмотреть контексты;
- добавить локальное значение;
- фильтровать записи;
- экспортировать текущий resolved lexicon кнопкой **Экспорт словаря CSV**.

## 8. Проверка текста

У каждой строки есть отметка `проверено`. В верхней панели редактора кнопка
**Проверить весь текст** отмечает все ещё непроверенные строки именем текущего
редактора, не перезаписывая уже существующее авторство проверки.

## 9. Экспорт

Доступны DOCX, JSON и CSV.

DOCX содержит двухстрочный IGT:

1. морфемы / сегментация;
2. глоссы.

FieldWorks `grammatical-info` не выводится отдельной третьей строкой DOCX, но
остаётся в данных и структурированных экспортах.

## 10. Данные

Все рабочие данные находятся в `data/`. При обновлении кода эту папку нельзя
заменять или удалять. Кодовый ZIP проекта может распространяться без `data/`;
при первом запуске и импорте необходимые подкаталоги создаются автоматически.
