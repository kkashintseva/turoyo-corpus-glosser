Новый текст

Вставьте новый текст. Одна строка — один интерлинейный блок. В режиме FLEx-corpus известные словоформы получают анализы из уже импортированного корпуса; неоднозначные разборы остаются альтернативами, неизвестные слова — пустыми.

Лексикон FieldWorks (LIFT)

Файл .lift становится основным словарём: каждая FieldWorks-entry остаётся отдельной, её варианты формы ведут в ту же entry, а grammatical-info (например Preterite, Infectum, Imperative) сохраняется как часть конкретного словарного анализа. Файл .lift-ranges можно приложить вместе с ним. Локальные новые слова и значения не стираются при повторном импорте.

Импорт корпуса FLEx

Файл .flextext / XML. Импортируются все <interlinear-text>: каждый текст становится редактируемой сессией, а подтверждённые разборы пополняют corpus-based parser. Исходный XML архивируется без изменений. До 100 МБ.

Импорт DOCX с готовой разметкой

Документ, где часть строк уже размечена вручную (IGT) — неразмеченные строки доглоссирует программа. До 25 МБ.
